## Block Conditions Reference

The PM agent issues a BLOCK (not a warning) for any of the following:

```
FINANCIAL_FLOAT_VIOLATION
float used instead of Decimal for any monetary value or quantity
Reference: CODING_STANDARDS.md — Financial Arithmetic section

ARCHITECTURE_BOUNDARY_VIOLATION
Engine module imports from repository layer
Router contains business logic
Service calls engine that calls another engine
Reference: ARCHITECTURE.md — Module Dependency Rules

MISSING_TEST_FILE
New corporate action handler exists without corresponding test file
Reference: DEVELOPMENT_SEQUENCE.md — Phase 3 build order

TEST_COVERAGE_BELOW_THRESHOLD
corporate_actions/ below 95%
reconstruction/ below 95%
wealth_engine/ below 90%
```
